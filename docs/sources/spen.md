# SP Energy Networks (SPEN: SPD Scotland, SPM Manweb) - Opendatasoft portal recon

Observed 2026-11-12, anonymous curl. Base: `https://spenergynetworks.opendatasoft.com/api/explore/v2.1/catalog/datasets`
Catalog: 171 datasets (includes `metadata-catalogue`, 171 rows, anonymously readable, and ~28 "Data Quality Checks" datasets).
SPD = SP Distribution (central/southern Scotland), SPM = SP Manweb (Cheshire, Merseyside, N Wales, N Shropshire). Per AI_GOTCHAS: in Scotland 132 kV is transmission (SPT); SPD LTDS covers 33 kV and below; SPM LTDS includes 132 kV.

## Access (read this first)
- **Only 23 of 171 datasets return rows anonymously.** 148 return HTTP 403 on `/records`; `/exports/csv` returns header only (checked on SPD LTDS fault levels). Metadata is public (`data_visible: false`). Presumably free registration/API key; not tested.
- Anonymously readable (23), the useful ones: DFES polygons (`spd-dfes-substation-polygons-gsp` 88, `-pss` 395; `spm-dfes-substation-polygons-gsp` 13, `-pss` 338, `-grid-group` 40), `spd-historic-feeder-utilisation` (3,109), `spd-ltds-appendix-6-connection-activity-table-6` (708), `spm-ltds-appendix-4-fault-levels-table-4-132kv-1ph-copy` (355, mod 2023-11-29 - old "copy"; current version is gated), `embedded-capacity-register-50kv-1mw` (2,662), `spen-weekly-substation-carbon-estimate` (389,774), flexibility (`pre_2026_flexibility_competitions_piclo` 26,647, `flexibility_substation_polygons_spm-piclo` 46, `competition-polygons-v1` 111, `flex_earnings_breakdown_spd/spm` 940/910), `spen_data_quality_*` (several), `carbon-accounting-for-substation-auxiliaries` (24), `roadmap-data` (62), `faq-dataset`, `spen-boundary-information0` (2), `metadata-catalogue`.
- Rate limit header seen: `x-ratelimit-limit: 5000`.
- Licence: CC BY 4.0 on 150 datasets, none stated on 21 (several of those are the current LTDS/DFES licence tables). GIS shapefile datasets (`spm_gis_shapefiles_*`, `spd_spt_gis_shapefiles_*`; 360,640 / 322,391 point assets, 2.9M-3.2M lines) require a form request and are under a Shared Data Licence (per description).
- Most datasets have a "Triage Process" PDF attached (documentation, not data).

## CRS / geometry
- WGS84: `geo_point_2d`/`geo_points` (ODS `{lon,lat}`), `geo_shape` GeoJSON (verified sample, e.g. SPD GSP polygon lon -3.70 lat 55.89); `latitude`/`longitude` doubles on heatmaps.
- BNG as text/double: `x`,`y` (DG heatmaps, double), ECR `location_xcoordinate_eastings_where_data_is_held` (text, gated).
- **ECR 50kW-1MW coordinates are deliberately coarse and mostly missing**: `x_eastings_1_km`/`y_northings_1_km` are 1 km-rounded BNG strings (e.g. "291000","312000"); 1,304 of 2,662 rows say "data not available". Also column misalignment seen: `licence_area` contains "0", "0.415", "11", "33" for 264 rows (shifted columns). Counts via group-by: SP Distribution 1,011, SP Manweb 743, data not available 644.

## Attachment-only / non-tabular
- Almost every dataset carries a "... Triage Process.pdf" attachment (docs). `spm-ltds-appendix-4-...-copy` also has the original XLSX attached. LTDS Appendix 9 (schematics) and 10 (geographic plans) and CIM profiles (3 rows) are likely file/link records (not inspected: gated). GIS shapefile datasets are request-form-gated.

## Join keys (observed)
- Names only for most (substation, primary_su, gsp, grid_group, substation_name+busbar_name) - use the naming reference tables.
- IDs: `substation_enid` (LCT), `transformer_enid` / `lv_transformer_enid` / `secondary_transformer_id` / `secondary_substation_id` (LV), `lv_feeder_id`, `substation_id` + `feeder_id` (feeder utilisation, e.g. "10291"/"1029112"), `sp_enid` (GIS), `group_id` (network flow), `unique_id` (project pipeline). Whether `substation_id` 10291 equals primary `substation_enid` was not verified (gated).

## Surprises
- 86% of datasets gated. Current LTDS fault-level tables (SPD/SPM) are gated; the only anonymous one is a stale 2023 "copy" of SPM 132 kV 1-ph.
- The anonymous set still gives: primary/GSP polygons (DFES), feeder RAG utilisation (SPD only), ECR 50kW-1MW with 1 km coords, connection activity.
- SPM 132 kV exists as distribution data; SPD stops at 33 kV (132 kV is SPT transmission).
- ECR 50kW-1MW has 49% missing coordinates and shifted columns.
- Weekly substation carbon estimate (389,774 rows, latest 2026-10-22) - tangential but open.
